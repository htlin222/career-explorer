# 生涯探索測驗（繁體中文）

給國中生用的三階段生涯探索工具。單一 HTML 檔，不需要後端、不需要註冊，
作答資料只留在使用者自己的瀏覽器。

## 三個階段

| 階段 | 量表 | 題數 | 產出 |
|---|---|---|---|
| 一 | RIASEC Markers | 48 | 何倫碼三碼、六型百分位、對應高中職群科 |
| 二 | Basic Interest Markers | 337 | 31 個具體興趣領域排名與升學方向 |
| 三 | IPIP-NEO-120 | 120 | 五大人格向度 + 30 個面向百分位 |

## 資料來源與授權

**RIASEC Markers（48 題）** — Liao, H.-Y., Armstrong, P. I., & Rounds, J. (2008).
*Journal of Vocational Behavior, 73*, 159–183. 公共領域。
青少年百分位常模由 Open-Source Psychometrics Project 資料集（CC0，2015–2018）
篩選 12–18 歲、完整作答者 n = 47,290 計算。

**Basic Interest Markers（337 題）** — 同上作者，**有版權**。作者授權專業人員
（研究者與實務工作者）非商業使用免費，須標註出處，不得商用。
作者群另有官方繁體中文版（廖新雅，Washington State University；胡昌亞，國立政治大學），
正式施測建議向作者索取。本專案的中文為非官方翻譯。
量表對應何倫碼的字母標籤為依 Holland 分類推定，非原論文對照表。

**IPIP-NEO-120** — 題目取自 International Personality Item Pool（公共領域）；
計分與常模依 Johnson, J. A. (2014). *Journal of Research in Personality, 51*, 78–89。
與 [rubynor/bigfive-web](https://github.com/rubynor/bigfive-web) 使用同一套題目。
最年輕的常模組為「未滿 21 歲」，國中生的百分位僅供粗略參考。

## 使用限制

自陳量表，非臨床診斷工具，測不出智力或能力。結果供生涯探索討論使用，
不應作為分流或篩選的依據。
